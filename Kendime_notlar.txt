1. Docker nedir?
Docker, uygulamaları ve bağımlılıklarını tek bir paket halinde çalıştıran bir konteyner teknolojisidir.
Yani uygulama aynı şekilde her bilgisayarda çalışır.

2. Docker ile sanal makine farkı nedir?
Sanal makine ayrı bir işletim sistemi çalıştırır.
Docker ise ana bilgisayarın çekirdeğini paylaşır.
Bu yüzden Docker daha hafif, daha hızlı ve daha az kaynak tüketir.

3. Docker Compose neden kullanılır?
Docker Compose, birden fazla konteyneri tek bir dosya ile yönetmek için kullanılır.
Örneğin web, veritabanı ve nginx gibi servisleri tek komutla başlatırız.

4. Docker image ile container farkı nedir?
Image, uygulamanın çalıştırılabilir kalıbıdır.
Container, bu imajın çalışan canlı örneğidir.
Yani image = şablon, container = çalışan nesne.

5. Compose ile kullanılan image ile kullanılmayan image farkı nedir?
Compose ile kullanılan image, birden fazla servisi aynı sistem içinde yönetmek için kullanılır.
Compose kullanılmayan image ise tek başına çalıştırılır ve manuel yönetilir.

Kısa özet:
Docker uygulamaları konteynerlerde çalıştırır.
Docker Compose ise çoklu konteynerleri tek yapılandırmada yönetir.

Kolay anlatım:
Docker = uygulamayı paketler.
Container = paketi çalıştırır.
Compose = birden fazla paketi birlikte yönetir.

En kısa cevaplar:
- Docker: Uygulama paketleme ve çalıştırma aracı.
- VM: Ağır, ayrı işletim sistemi.
- Container: Hafif, aynı kernel paylaşan çalışma ortamı.
- Image: Çalıştırılabilir kalıp.
- Compose: Çoklu konteyner yönetimi.





/* 

/requirements/mariadb/Dockerfile dosyası

Burada Dockerfile, Debian Buster tabanlı bir image kullanarak MariaDB server ve client kurar.
MariaDB yapılandırma dosyasını ve otomatik veritabanı oluşturma betiğini konteyner içine kopyalar ve betiğe çalıştırma izni verir.

- apt-get update -y  = paket listelerini günceller.
- apt-get install -y mariadb-server mariadb-client =  MariaDB sunucusunu ve istemcisini kurar.
- apt-get clean ve rm -rf /var/lib/apt/lists/* =  bu iki komut gereksiz dosyaları temizleyerek image boyutunu küçültür.
- COPY  = bu copy komutları, MariaDB yapılandırma dosyasını ve otomatik veritabanı oluşturma betiğini konteyner içine kopyalar.
- RUN chmod +x /auto_db.sh =  betiğe çalıştırma izni verir.
- ENTRYPOINT ["/auto_db.sh"]  =  konteyner başlatıldığında otomatik olarak betiğin


*/
